
Тип дієслова 5 зустрічається досить рідко порівняно з іншими фінськими типами дієслів. Дієслова, що належать до цього типу, закінчуються на _**<font color="#2DC26B">-ita/-itä</font>**_ **. Щоб знайти інфінітивну основу** цього типу дієслова , потрібно **видалити кінцеву** ==**_<font color="#2DC26B">-ta/-tä</font>==_** . До цієї основи потрібно потім додати ==_**<font color="#2DC26B">-tse</font><font color="#2DC26B">-</font>==,**_ перш ніж додати **особове закінчення** !

Деякі джерела пропонують інше правило. Вони рекомендують видалити _**-ita/-itä**_ (а отже, видалити і _-i-_ ) та **додати** ==**_<font color="#2DC26B">-itse-</font>_**== до основи речення, перш ніж додавати особове закінчення. Кінцевий результат той самий, тому оберіть той метод, який вам більше підходить.

| ------ | -------------------------------------------- | --- |
| sä     | hall<font color="#2DC26B">itse</font>==t==   |     |
| hän/se | hall<font color="#2DC26B">itse</font>==e==   |     |
| me     | hall<font color="#2DC26B">itse</font>==mme== |     |
| te     | hall<font color="#2DC26B">itse</font>==tte== |     |
| he     | hall<font color="#2DC26B">itse</font>==vat== |     |
### Дієслова 5-го типу не зазнають градації приголосних.
- halita (правити, керувати, володіти)
- havaita (сприймати)
- hallita (стримувати)
- häiritä (заважати, турбувати)

- kyyditä (підвезти когось)
- mainita (згадувати)
- merkitä(позначати tai маркувати)
- punnita (зважити)

- palkita (нагороджувати, нагороджувати)
- tarvita (потребувати)
- tulkita (тлумачити)

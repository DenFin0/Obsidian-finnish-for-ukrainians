При відмінювані прикметника на прислівника береться основа і додається закінчення -sti.

| Прикметник | Прислівник |
| ---------- | ---------- |
| kaunis     | kauniisti  |
| valmis     | valmiisti  |
| kallis     | kalliisti  |
| yleinen    | yleisesti  |
| tärkeä     | tärkeästi  |
Прикметники які закінчуються на -nen.

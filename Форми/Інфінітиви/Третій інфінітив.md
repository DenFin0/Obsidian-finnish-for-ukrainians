## 2. Використання третього інфінітива

Третій інфінітив використовується, коли **поєднуються два дієслова** . Найпоширеніші відмінки, в яких ви зустрінете його, це ілатив ( _-maan_ ), ініціативний відмінок ( _-massa_ ) та елатив ( _-masta_ ), часто стосовно дієслів _mennä,_ _olla_ та _tulla_ .
### 2.1. Missä ( _olen lukemassa_ )

У ситуаціях, коли місцезнаходження з'являється у формі [_missä_](https://uusikielemme.fi/finnish-grammar/location-cases/the-inessive-case-missa/) (наприклад, _istun ravintolassa_), ми також можемо мати дієслово, яке описує дію, яку ми виконуємо в цьому місці (наприклад, _istun syömässä_ ). Ви **можете** сказати обидва в одному реченні (наприклад, _istun ravintolassa syömässä_ ), але обидва також можуть використовуватися окремо.

### 2.2. Mistä ( _tulen lukemasta_ )

Такі дієслова, як _lähteä_ «йти» та _tulla_ «приходити звідки», виражають рух від місця. У фінською мовою для таких ситуацій використовується форма [_mistä -_](https://uusikielemme.fi/finnish-grammar/grammatical-cases/the-elative-case-mista-finnish-grammar/) _(наприклад, tulen koulusta_ ). Якщо ми додаємо дію, з якої повертаємося, ця дія буде у формі _masta -_ (наприклад, _tulen opiskelemasta_ ). Обидва також можуть зустрічатися в одному реченні: _Tulen koulusta opiskelemasta._ «Я прийшов зі школи після навчання». 

| Фінська                                   | Англійська                             |
| ----------------------------------------- | -------------------------------------- |
| Tulen Prismasta osta<u>masta</u> kukkia.  | Я приходжу з Прізми купивши квітів.    |
| Nousen vihdoin sängystä luke<u>masta</u>. | Я нарешті встаю з ліжка після читання. |
| Lähden kylpyhuoneesta itke<u>mästä</u>.   | Я виходжу з ванної кімнати плачучи.    |
| Tulen Espanjasta lomaile<u>masta</u> .    | Я приїхав з Іспанії «з» відпустки.     |

### 2.3. Mihin (_menen lukemaan_)

Такі дієслова, як [^3]_mennä_ , [^2]_saapua_ та [^4]_astua_, виражають рух до місця (наприклад, _menen kouluun_ ). Для дієслів, а також іменників, ми будемо використовувати форму [_mihin_](https://uusikielemme.fi/finnish-grammar/grammatical-cases/the-illative-case-mihin/) у цих ситуаціях (наприклад, _menen kouluun opiskelemaan_ ). Дія може відображатися як окремо від місця, так і поруч із ним (наприклад, _menen opiskelemaan_ ).

| Фінська                                      | Англійська                                    |
| -------------------------------------------- | --------------------------------------------- |
| Menen kauppaan osta<u>maan</u> kukkia.       | Я йду до магазину купувати квіти.             |
| Lähden puistoon otta<u>maan</u> aurinkoa.    | Я йду в парк засмагати.                       |
| Saavun baariin tapaa<u>maan</u> kavereitani. | Я приходжу до бару, щоб зустрітися з друзями. |
| Menen Egyptiin sukelta<u>maan</u>.           | Я їду до Єгипту пірнати.                      |
*Примітка: в розмовній мові третій інфінітив часто втрачає свій маркер, через що дієслово майже невпізнанне для тих, хто вивчає мову: [^6]meen nukkuun(йди спати), [^5]tuu kattoon(Іди подивися) .*
### 2.4. Millä ( _opin puhumalla_ )

Це використовується, коли ви хочете сказати, як ви щось робите, «роблячи що». Це [обраний відмінок](https://uusikielemme.fi/finnish-grammar/grammatical-cases/the-adessive-case-milla/) .

| Фінська                                       | Англійська                                    |
| --------------------------------------------- | --------------------------------------------- |
| Opin suomea puhu<u>malla</u> ystävilleni.     | Я вивчаю фінську мову, спілкуючись з друзями. |
| Rentoudun hengittä<u>mällä</u> rauhallisesti. | Я заспокоююся, спокійно дихаючи.              |
| Lukitsen oven kääntä<u>mällä</u> avaimen.     | Я замикаю двері, повертаючи ключ.             |
| Varoitin ihmisiä huuta<u>malla</u>.           | Я попереджав людей криками.                   |

### 2.5. Abessive (_olin syömättä_)

Це використовується, коли ви хочете сказати «те, чого ви втратили», роблячи щось. У цих прикладах використовується [пристрастний відмінок](https://uusikielemme.fi/finnish-grammar/grammatical-cases/the-abessive-case-tta-tta-abessiivi/) .

| Finnish                                          | Українська                               |
| ------------------------------------------------ | ---------------------------------------- |
| Olin 3 päivää syö<u>mättä</u>.                   | Я 3 дні не їв                            |
| Poistuin talosta hengittä<u>**mättä**</u> savua. | Я вийшов з дому <u>не вдихнувши</u> диму |
| Hän aloitti luke**<u>matta</u>** sääntöjä.       | Він почав, <u>не прочитавши</u> правила  |
| Lähdin sano**<u>matta</u>** sanaakaan.           | Я пішов <u>не сказавши</u> ні слова      |
### 2.6. Повчальний
Вказівна форма третього інфінітива майже не використовується. Вона може зустрічатися з дієсловом _pitää_ у фразах на кшталт « _Mitä minun pitikään sano**man**_ » (Що я хотів ще раз сказати) або « _Sinun pitää lähte**män**_ » (Тобі слід піти). Це НЕ той тип речення, який вам потрібно буде скласти самостійно в будь-якій ситуації.

### 2.7. Дієслово + дієслово

Деякі дієслова часто використовуються в поєднанні з третім інфінітивом. Ці дієслова мають «третю інфінітивну реакцію». Деякі з них конкретно позначають рух (повертатися «з» кудись, спати «в» десь), але інші є набагато абстрактнішими. Наприклад, дієслово «забороняти» вимагає третього інфінітива: у фінською мовою ви забороняєте комусь щось робити.

| Finnish                         | Українська                   |
| ------------------------------- | ---------------------------- |
| Kielsin sinua tule**masta**.    | Я забороняю тобі приходити   |
| Pyydän sinua odotta**maan**.    | Прошу вас зачекати           |
| Jouduin odotta**maan**.         | Мені довелося чекати         |
| Kannustin sinua yrittä**mään**. | Я заохочував тебе спробувати |
### 2.8. Дієприкметник агента
Цей дієприкметник використовується як прикметник у фразах на кшталт _pojan teke**mä** vene_ (човен, який зробив хлопчик).

| Фінська                                | Українська                                 |
| -------------------------------------- | ------------------------------------------ |
| (Äidin leipo**ma** kakku) on paras.    | (Торт, який спекла мама), найкращий.       |
| Rakastan (äidin leipo**ma**a kakkua).  | Мені подобається (торт, який спекла мама). |
| (Kirjoitta**ma**ni kirje) ei saapunut. | (Лист, який я написав) не прийшов.         |
| (Rakenta**ma**si vaja) lässähti.       | (Сарай, який ти збудував) розвалився.      |

### 2.9. Майже: _nukkumaisillaan_ (майже _повністю_)

Третій інфінітив також лежить в основі конструкції речення, яка приблизно перекладається як «на межі чогось зробити; ось-ось щось зроблю». Ви завжди використовуватимете маркер – **mAisillA-** з присвійним суфіксом у самому кінці.

| Finnish                                     | English                                        |
| ------------------------------------------- | ---------------------------------------------- |
| Olin (nukku**maisillani**) kun kello soi.   | Я вже (майже заснув), коли продзвенів дзвінок. |
| Mari oli (tukehtu**maisillaan**) ruokaansa. | Марі (майже не вдавилася) їжею.                |
| Hän oli (hyppää**mäisillään**) sillalta.    | Він (майже не стрибнув) з мосту.               |
| Olimme (näänty**mäisillämme**) nälkään.     | Ми (майже померли) з голоду.                   |
